Week 02 Reflection

This week introduced different methods of assigning static IP addresses and testing network connectivity. 
I learned three approaches: configuring through GNS3 settings, editing /etc/network/interfaces, and using the ip address add command.
I also explored the ping command to test connectivity and measure round-trip time (RTT).
One important insight was the difference between temporary and persistent configurations. 
I also understood how packet loss and delay indicate network issues.
