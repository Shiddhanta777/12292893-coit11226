
This week focused on ARP and default gateways, linking different networking layers.
By observing ARP tables, I learned how devices map IP addresses to MAC addresses dynamically.
Configuring default gateways showed how devices communicate across multiple subnets.
I did not initially realise how frequently ARP updates occur during communication.
After testing multiple pings, I understood how ARP entries change over time.
This concept is critical in real-world troubleshooting, especially when diagnosing connectivity issues within a LAN.
